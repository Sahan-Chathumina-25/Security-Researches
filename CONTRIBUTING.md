# Contributing

## Scope

This repository documents independent security research. It is not a
vulnerability-dispatch service and does not publish exploit material.
Contributions that are appropriate:

1. **Corrections** — if a finding, version range, classification or link is
   factually wrong, open an issue describing the error and the supporting
   evidence.
2. **Clarifications** — improvements to documentation readability,
   methodology descriptions, or repository structure.
3. **Website** — fixes to the GitHub Pages site (broken links, styling,
   accessibility).

## Not accepted

- Requests to publish exploitation details, PoC scripts, or trigger inputs
  for findings that remain unpatched upstream. These are withheld
  deliberately under the disclosure process; see
  [findings/DISCLOSURE-STATUS.md](findings/DISCLOSURE-STATUS.md).
- Vulnerability submissions for third-party software. This repository
  documents research, it does not accept reports; third-party issues belong
  to the respective upstream project's security policy.
- Claims not supported by reproducible evidence.

## Process

1. Check the [findings index](FINDINGS-INDEX.md) and the relevant finding
   report first.
2. Open a GitHub issue with the subject prefixed `DOC:` (documentation) or
   `SITE:` (website).
3. Small fixes may be submitted as pull requests referencing the issue.
4. Substantive changes will be reviewed against the original research
   records for accuracy before merging.
