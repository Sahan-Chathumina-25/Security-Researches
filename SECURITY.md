# Security Policy

## Reporting an issue in this repository

If you find sensitive material in this repository that you believe should not
be public — for example, reproduction details for an unpatched vulnerability,
credentials, or private vendor communications — please do not open a public
issue.

Use GitHub's private vulnerability reporting feature on this repository, or
contact the maintainer via the GitHub profile:
<https://github.com/Sahan-Chathumina-25>.

## Content handling

- This repository documents independent security research. Findings that
  were unpatched upstream at documentation time are published only in
  redacted form, without exploitation material.
- Redacted details may be restored to full reports after upstream fixes ship
  or vendor advisories are published, in coordination with the respective
  projects' disclosure processes.

## Supported content

Documentation, methodology, findings index, and website pages in this
repository are maintained on a best-effort basis alongside the research
archive.
